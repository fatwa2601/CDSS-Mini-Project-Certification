# Healthcare Data Analysis (CDSS Mini Project)

## Description
This project analyzes a healthcare business case using dummy data to generate insights for decision making.

## Objective
- Identify healthcare problems
- Define KPIs and success metrics
- Analyze data and generate insights

## Tools
- Python
- VS CODE

## Process
- Defined business problem
- Set KPIs
- Conducted EDA
- Generated insights

## Key Insights
- Patients with previous no-shows are much more likely to miss future appointments.
- Longer waiting times (>40 minutes) are associated with higher no-show rates.
- Missed appointments lead to unused time slots and lost revenue.
